<br />

**Imibavu Collection** is a single-page application (SPA) built entirely with **vanilla HTML, CSS, and JavaScript**. No frameworks, no bundlers, no dependencies — just clean, performant code that loads fast on any device.

The site showcases a curated selection of **trending Arabic fragrances** (Lattafa, Mousuf), **designer-inspired perfumes**, **long-lasting summer scents**, **custom oil blends**, and **minimalist jewelry**.

## 🚀 Getting Started

### 📋 Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local static server — any of these:

| Tool | Command |
|------|---------|
| **Python 3** | `python3 -m http.server 8000` |
| **Node.js** | `npx serve -l 8000` |
| **PHP** | `php -S localhost:8000` |
| **VS Code** | Live Server extension |

### ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-org/imibavu-collection.git
cd imibavu-collection
```

**2. Serve locally**

```bash
# Python 3
python3 -m http.server 8000

# or Node.js
npx serve -l 8000

# or PHP
php -S localhost:8000
```

**3. Open in your browser**

```plaintext
http://localhost:8000
```

> ⚠️ **Note:** Opening `index.html` directly via `file://` works, but hash routing and `localStorage` behave best over `http://`.

## ⚙️ Configuration

All business-level configuration lives in `js/data.js` and `js/i18n.js`.

### 🏪 Store Information

Update these in `index.html`:

| What | Where | Example |
|------|-------|---------|
| **WhatsApp number** | `href="https://wa.me/250784804739"` | 3 occurrences |
| **Phone number** | `href="tel:+250784804739"` | Footer |
| **Address** | `.f-addr` block | Footer |
| **Social links** | `.f-social` block | Footer |
| **Opening hours** | `.f-hours` block | Footer |
| **Promo banner** | `js/i18n.js` → `promo_text` | Top of page |

### 🛍️ Adding Products

Edit `js/data.js`:

```javascript
{
  id: "lattafa-khamrah",
  name: "Khamrah",
  brand: "Lattafa",
  category: "perfumes",
  collection: "arabic",
  price: 45000,
  compareAt: 55000,
  sizes: [
    { ml: 100, price: 45000, stock: 12 },
    { ml: 50,  price: 28000, stock: 5  }
  ],
  notes: {
    top: "Cinnamon",
    heart: "Praline",
    base: "Vanilla"
  },
  rating: 4.8,
  reviews: 34,
  images: [
    "assets/img/products/khamrah-1.jpg",
    "assets/img/products/khamrah-2.jpg"
  ],
  badges: ["trending"],
  description: "Warm, gourmand, long-lasting..."
}
```

### 🌍 Adding Translations

Edit `js/i18n.js`:

```javascript
export const translations = {
  en: {
    nav_home: "Home",
    nav_shop: "Shop",
    // ...
  },
  rw: {
    nav_home: "Ahabanza",
    nav_shop: "Iduka",
    // ...
  },
  fr: {
    nav_home: "Accueil",
    nav_shop: "Boutique",
    // ...
  }
};
```

Then add the option in `index.html`:

```html
<select id="langSelect">
  <option value="en">EN</option>
  <option value="rw">RW</option>
  <option value="fr">FR</option>
</select>
```

## 🌍 Internationalization

### 🔧 How It Works

| Step | Action |
|------|--------|
| **1** | Elements marked `data-i18n="key"` get their text replaced |
| **2** | Elements marked `data-i18n-ph="key"` get their placeholder replaced |
| **3** | Language stored in `localStorage` under `imibavu:lang` |
| **4** | Changing the `<select>` re-renders all translated nodes |

### ➕ Adding a Language

**Step 1:** Add to `js/i18n.js`

```javascript
export const translations = {
  en: { /* ... */ },
  rw: { /* ... */ },
  fr: { /* ... */ },
  sw: {  // ← New language
    nav_home: "Nyumbani",
    nav_shop: "Duka",
    // ...
  }
};
```

**Step 2:** Add option in `index.html`

```html
<select id="langSelect">
  <option value="en">EN</option>
  <option value="rw">RW</option>
  <option value="fr">FR</option>
  <option value="sw">SW</option>
</select>
```

> 💡 **Missing keys fall back to English automatically.**

## 🛒 E-Commerce Flow

```plaintext
┌─────────────────┐     ┌──────────────────┐     ┌────────────────────┐
│   Browse        │────▶│   Add to Cart    │────▶│   Cart Drawer      │
│   Shop / PDP    │     │   (localStorage) │     │   (adjust qty)     │
└─────────────────┘     └──────────────────┘     └─────────┬──────────┘
                                                           │
                                                           ▼
                                                 ┌────────────────────┐
                                                 │   Checkout Page    │
                                                 │   (name, phone,    │
                                                 │    delivery)       │
                                                 └─────────┬──────────┘
                                                           │
                                                           ▼
                                                 ┌────────────────────┐
                                                 │   WhatsApp Order   │
                                                 │   (pre-filled msg) │
                                                 └────────────────────┘
```

> 💡 **No payment gateway.** Orders are confirmed manually via WhatsApp, then fulfilled in-store or by delivery within Kigali.

### 💾 Cart Persistence

Cart is saved to `localStorage` under `imibavu:cart`:

```json
{
  "items": [
    { "id": "lattafa-khamrah", "size": 100, "qty": 2 },
    { "id": "mousuf-tobacco", "size": 50, "qty": 1 }
  ],
  "updatedAt": "2025-01-15T10:30:00Z"
}
```

### 📱 Order Message Format

When the customer taps **"Order on WhatsApp"**, `app.js` builds a `wa.me` link with a URL-encoded message:

## ⚡ Performance

### ✅ Current Optimizations

| Optimization | Benefit |
|-------------|---------|
| No JS framework | Zero hydration cost |
| CSS custom properties | Minimal repaints |
| Single stylesheet | One HTTP request |
| Inline SVG icons | No icon font requests |
| `preconnect` + `display=swap` | Faster font load |
| Lazy-loaded images | Reduced initial payload |
| Hash routing | No server round-trips |

- [ ] Serve images as **WebP/AVIF** with `<picture>`
- [ ] Add `loading="lazy"` and `decoding="async"` to product images

- [ ] Enable **Brotli/Gzip** on host
- [ ] Add a **service worker** for offline catalog
- [ ] Add `<link rel="preload">` for hero image

## 📦 Deployment

### 🟢 Netlify

```bash
# Option 1: CLI
npm install -g netlify-cli
netlify deploy --prod

# Option 2: Git
# Connect repo → set publish directory to "/" → deploy
```

### ▲ Vercel

```bash
npm install -g vercel
vercel --prod
```

### 🐙 GitHub Pages

```bash
git subtree push --prefix . origin gh-pages
# Then enable Pages in repo settings
```

### ☁️ Cloudflare Pages

```plaintext
Connect repo → Build command: (none) → Output directory: /
```

### 🖥️ Traditional Hosting (cPanel / FTP)

Upload all files to `public_html/`. Ensure `.htaccess` allows JS and CSS MIME types (usually default).

### 🔒 Recommended Cache Headers

```nginx
/css/*   → Cache-Control: public, max-age=31536000, immutable
/js/*    → Cache-Control: public, max-age=31536000, immutable
/*.html  → Cache-Control: public, max-age=0, must-revalidate
```

## 🤝 Contributing

Contributions are what make the open-source community amazing. Any contribution you make is **greatly appreciated**.

### 🌿 Branching Strategy

```plaintext
main        → production
develop     → integration
feature/*   → new features
fix/*       → bug fixes
content/*   → copy and translation
```

### 📝 Commit Convention

```bash
feat: add scent finder quiz
fix: correct cart total rounding
style: refine product card hover
content: translate FAQ to Kinyarwanda
docs: update deployment guide
```

### ✅ Pull Request Checklist

- [ ] Tested on mobile (Chrome DevTools + real device)
- [ ] Tested with keyboard only
- [ ] Tested with `prefers-reduced-motion: reduce`
- [ ] No console errors
- [ ] Lighthouse ≥ 95 across all categories
- [ ] Translations updated for all 3 languages

### 🚀 Quick Start for Contributors

```bash
# 1. Fork the repo
# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/imibavu-collection.git

# 3. Create a feature branch
git checkout -b feature/amazing-feature

# 4. Make your changes
# 5. Commit
git commit -m "feat: add amazing feature"

# 6. Push
git push origin feature/amazing-feature

# 7. Open a Pull Request
```
